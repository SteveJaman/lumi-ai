The core difference between Lumi and Neuro is not intelligence.
It is ARCHITECTURE. Neuro runs continuously, has internal state,
makes its own decisions, and acts without being prompted.

Lumi waits. Neuro lives.

Every item below closes that gap. Ordered by dependency —
later items assume earlier ones are done.

  PHASE 4 — EPISODIC MEMORY (temporal depth)            ✅ COMPLETE
================================================================

[X] 4.1  Upgrade memory schema                          DONE
         Files:     modules/memory.py
         Status:    Every stored fact carries:
                      timestamp  (ISO, seconds precision)
                      importance (0.0-1.0, model-scored)
                      valence    (one-word emotion or null)
                      session_id (per-run, for grouping)
                    Old memories without these fields are
                    backfilled with safe defaults on import.

[X] 4.2  Weight retrieval by recency and importance     DONE
         Files:     modules/memory.py
         Status:    Combined score:
                      W_SIMILARITY (0.50) * (1 - distance)
                    + W_IMPORTANCE (0.30) * importance
                    + W_RECENCY    (0.20) * exp(-age/half_life)
                    Half-life is 30 days. Over-fetches 3×
                    the recall count, reranks, keeps top N.
                    Age hints ("(yesterday)", "(2d ago)",
                    "(3w ago)") appended to each recalled
                    fact in the injection.

[X] 4.3  "When did we..." queries                       DONE
         Files:     modules/memory.py, modules/prompter.py
         Status:    Two surfaces:
                      · !recall <query> — terminal command,
                        oldest-first, importance markers,
                        age hints, [+ timestamp]
                      · recall_memory(query, since) — 9th
                        agent tool, model-callable, same
                        output format, injected into the
                        tool-result stream
                    Temporal hints ("yesterday", "last week",
                    "3 days ago") parsed via _parse_temporal_hint
                    in both the injection and query paths.
                    Verified: !recall perception → 10 hits,
                    sorted oldest-first, correct markers.

[X] 4.4  Reflection prompt crash fix                    DONE
         Files:     modules/memory.py
         Status:    REFLECTION_PROMPT used str.format() but
                    contained literal JSON braces in its
                    example output, producing
                    KeyError: '"fact"' on every reflection
                    pass. Switched to a <<CHAT_SECTION>>
                    sentinel + .replace(), so braces in the
                    prompt body are inert.
         Verified:  Reflection loop runs cleanly across
                    restarts. DB grew 43 → 48 → 52 → 57
                    over four sessions with no errors.

[-] 4.5  (Optional) Normalize import_json timestamps    LOW PRIORITY
         Files:     modules/memory.py
         Status:    Three imported memories show
                    [unknown] timestamps in !recall output.
                    Cause: import_json uses meta.setdefault()
                    which skips already-present-but-empty
                    values. Fix: replace setdefault with
                    explicit truthiness check. Requires a
                    wipe + reimport to apply retroactively.
         Impact:    Cosmetic. Those facts still surface on
                    semantic queries; they just can't be
                    placed in time.
